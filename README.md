# Project-Admin-Dashboard

## Live Demo
[View the live project] https://dokudemo.github.io/Project-Admin-Dashboard/

## About the Project

Admin Dashboard is a dashboard interface with a sidebar navigation, header section, user information, search field, project cards, announcements, and a trending users section.

This project helped me practice:

- Building complex layouts with CSS Grid
- Dividing a page into main layout areas
- Using Flexbox for alignment
- Creating responsive card grids
- Working with `:hover`, `:active`, and `:focus-visible`
- Using SVG icons
- Creating and using CSS custom properties
- Styling interactive interface elements

## Features

- Sidebar navigation
- Header with a search field and user information
- `New`, `Upload`, and `Share` buttons
- Project cards grid
- Announcements section
- Trending users section
- Hover effects for links and buttons
- Visible focus styles for keyboard navigation
- CSS Grid-based page layout
- Flexbox-based element alignment

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Custom Properties
- SVG
- Google Fonts
- Git

## Project Goal

The goal of this project is to practice building complete user interfaces with HTML and CSS and to improve my understanding of layout systems such as Grid and Flexbox.
